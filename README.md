# CS-300-11308-M01-DSA-Analysis-and-Design-
CS-300: Data Structures and Algorithms: Analysis and Design focuses on learning how to organize data and write efficient code using C++. Students work with data structures like vectors, linked lists, hash tables, and binary search trees.

What was the problem you were solving in the projects for this course?

The main problem I was solving was figuring out how to organize, store, search, and sort data efficiently. In Project One, I worked with different data structures, including vectors, linked lists, and hash tables, to store and manage bids. In Project Two, I applied what I learned to create a program that loads course information, checks prerequisites, and displays courses in alphanumeric order. These projects helped me understand how different data structures can be used to solve problems.

How did you approach the problem? Why are data structures important to understand?

I approached each project by breaking the problem into smaller steps and working through them one at a time. I learned how different data structures work and compared their performance in terms of runtime and memory usage. Data structures are important because the way information is stored can affect how quickly a program runs and how much memory it uses. Choosing the right structure can make a program more efficient and easier to work with.

How did you overcome any roadblocks you encountered?

When I ran into problems, I worked through the code, checked for errors, and tested different parts of the program to figure out what was going wrong. Some challenges involved getting the functions to work correctly and making sure the program could load, search, and display information as expected. I also learned that paying attention to details and testing my code regularly can save time and prevent bigger problems later.

How has your work on this project expanded your approach to designing software and developing programs?

These projects helped me understand that writing a program involves more than just getting the code to work. I also need to consider how efficiently it handles data and whether the approach makes sense for the problem. Before this class, I might have focused mostly on getting the correct output. Now, I am more likely to consider runtime, memory usage, and which data structure would work best for the situation.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I have learned the importance of organizing code into separate functions, using clear names, and keeping the program structured so it is easier to understand. Breaking a program into smaller pieces also makes it easier to find errors and make changes without affecting everything else. Going forward, I want to keep improving how I organize and document my code so that it is easier for me or another developer to maintain, update, and build on it in the future.
